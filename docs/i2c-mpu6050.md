# I²C 与 MPU6050

I²C1 使用 7 位设备地址。BSP 在调用 STM32 HAL 时左移一位。短寄存器读写可选轮询，连续采样可用中断。中断传输由 `startRead/startWrite` 启动并保存票号，其他任务此时申请总线会收到 `Busy`。传输完成用 `wait` 取最终结果，读结果仅在成功时写入调用方缓冲。每次最多 64 字节。集成版的 I²C 完成及错误回调按实例释放 CubeMX 创建的二值信号量 `i2cDone`，等待任务沿用启动时的截止时间，并在唤醒后核对 HAL 的最终状态。下述固定版 `ead95fe` 是此前独立构建的步骤五固件。

每个已启动请求必须调用 `wait` 或 `cancel`。中断关闭、硬件 BUSY 或传输超时后支持复位 I²C1、清 NVIC 待处理事件并用原 CubeMX 参数重新初始化。手动 `recover` 会使旧票号失效。SDA 被外部持续拉低时需要排查接线或给故障器件重新上电。

模块依次查询 0x68 和 0x69 地址的 WHO_AM_I，期望值均为 0x68。初始化将采样率配置为 125 Hz，低通配置为 3，量程为 ±2 g、±250 °/s，并回读四个配置字节。采样一次突发读取 14 字节，包含加速度、原始温度和角速度。转换使用 16384 LSB/g、131 LSB/(°/s)。

上板时分别用轮询和中断读取同一块静止传感器，保存三轴原始数据，换算后核对重力方向。断开传感器应有明确错误，重新接线后执行恢复和初始化，再取一组样本。记录板卡、地址、接线与固件版本。

参考资料：[TDK MPU-6050 产品资料](https://www.invensense.tdk.com/en-us/products/motion-tracking/6-axis/mpu-6050)。

## 步骤五上板

### 版本与配置

固件源码固定在 `ead95fe`。用 J-Link 通过 SWD 连接 F103，打开 [步骤五 Ozone 工程](../boards/f103/f103-imu.jdebug)。工程加载同目录下的 `build/imu/f103.elf`。该版的 CubeMX 工程为 `build/imu-src/boards/f103/f103.ioc`，I²C1 速率为 100 kHz，PB6 为 SCL，PB7 为 SDA，启用事件及错误中断。

在新的检出目录中，从仓库根目录执行以下 PowerShell 命令即可生成同一路径的 ELF。若已有该固定工作树，直接从第二行开始。

```powershell
git worktree add --detach build/imu-src ead95fe
$outDir = Join-Path (Get-Location) 'boards/f103/build/imu'
Push-Location build/imu-src/boards/f103
cmake --preset Debug -B $outDir
cmake --build $outDir
Pop-Location
```

### 操作和预期

1. 断电后断开舵机电源和信号线，保留已验证的 J-Link、USB-TTL 和主板供电。对支持 3.3 V 供电的 MPU6050 模块，将 VCC 接 F103 的 3.3V，GND 接 GND，SCL 接 PB6，SDA 接 PB7。I²C 信号上拉到 3.3 V。若模块已有上拉，沿用其配置。INT、XDA、XCL 留空。固件依次探测 AD0 对应的两个地址。
2. 模块平放。串口助手打开 COM4，选择 115200、8N1、HEX 发送、文本接收。Ozone 打开步骤五工程，启动调试并继续运行。预期有 `[RTOS][Ok] Sensor/Monitor startup` 和 `[MPU][Ok] WHO_AM_I and config readback`。后者表示身份和配置均通过比较。正常时每 20 ms 采样，约每秒输出一组六轴原始值、X 轴换算值及监测信息。
3. 首轮手动各发一次表中前两帧，保留从复位到首组数据的完整串口记录。随后用同样的放置方向测试中断模式与错误恢复。遇到第一条错误时保留原始状态与回包。

| HEX 帧 | 操作 | 预期结果 |
| --- | --- | --- |
| `A5 20 00 C5` | 阻塞初始化 | `[MPU][Ok] WHO_AM_I and config readback` |
| `A5 21 00 C6` | 阻塞采样 | `[MPU][Ok] acc=… gyro=…` 和 `ax_mg=… gx_mdps=…` |
| `A5 20 01 C6` | 中断初始化 | 身份与配置回读成功 |
| `A5 21 01 C7` | 中断采样 | 记录静止时六轴原始值，再缓慢倾斜一次，观察加速度如何在各轴间变化 |
| `A5 22 00 C7` | 探测未使用地址 0x67 | 有传感器且总线正常时，预期 `[I2C][BusError] probe 0x67` |
| `A5 21 01 C7` | 错址后的正常采样 | 再次取得六轴数据 |

`[SENSOR][Ok] command enqueue` 只确认命令已入队。以其后的 MPU 或 I2C 行判断实际结果。静止时加速度矢量的模应接近 16384 个原始计数（约 1 g），单轴读数随放置方向变化。另测无设备工况时，断电后移除模块，上电记录初始化结果，再断电接回模块，上电后用表中初始化和采样帧复核。
