# I²C 与 MPU6050

I²C1 使用 7 位设备地址。BSP 在调用 STM32 HAL 时左移一位。短寄存器读写可选轮询，连续采样可用中断。中断传输由 `startRead/startWrite` 启动并保存票号，其他任务此时申请总线会收到 `Busy`。传输完成用 `wait` 取最终结果，读结果仅在成功时写入调用方缓冲。每次最多 64 字节。

每个已启动请求必须调用 `wait` 或 `cancel`。中断关闭、硬件 BUSY 或传输超时后支持复位 I²C1、清 NVIC 待处理事件并用原 CubeMX 参数重新初始化。手动 `recover` 会使旧票号失效。SDA 被外部持续拉低时需要排查接线或给故障器件重新上电。

模块依次查询 0x68 和 0x69 地址的 WHO_AM_I，期望值均为 0x68。初始化将采样率配置为 125 Hz，低通配置为 3，量程为 ±2 g、±250 °/s，并回读四个配置字节。采样一次突发读取 14 字节，包含加速度、原始温度和角速度。转换使用 16384 LSB/g、131 LSB/(°/s)。

上板时分别用轮询和中断读取同一块静止传感器，保存三轴原始数据，换算后核对重力方向。断开传感器应有明确错误，重新接线后执行恢复和初始化，再取一组样本。记录板卡、地址、接线与固件版本。
