# CAN

F103 的 bxCAN 使用 500 kbit/s。APB1 为 36 MHz，预分频 4，位时序 1 + 14 + 3 TQ，采样点约 83.3%。BSP 接受 11 位标准数据帧，允许 ID 0 至 0x7FF、DLC 0 至 8，禁止自动重传；数据帧在没有 ACK 时能结束本次失败。

`configure(true, mode)` 启动片内静默回环，单板即可验证发送及接收。传输模式可选轮询或中断。轮询检查对应邮箱的 RQCP、TXOK 位；中断发送从邮箱完成回调取最终结果。写入邮箱只代表请求已提交。中断接收从 FIFO0 入 8 帧单生产者队列。硬件 FIFO 和软件队列的溢出均返回 `Overflow`。集成版用 CubeMX 的 `canTxDone` 和 `canRxReady` 分别唤醒发送及接收等待任务。邮箱结果与接收队列保留实际状态。

`startSend` 返回票号，随后用 `waitSent` 或 `cancel` 完成本次请求。`send` 合并这两步。超时会重新初始化 CAN 并清理邮箱。掉线可人工执行 `recover`，恢复使用当前的工作模式，接收队列随之清空。接收超时返回 `Timeout`。

外部总线需切换到 `configure(false, mode)`。PA12/TX 和 PA11/RX 接收发器的 TXD/RXD，两节点共地、CANH/CANL 对应连接，两端各 120 Ω，双方波特率一致。在对端能提供 ACK 时，发送一帧有标识的数据并记录对端实际收到的 ID、长度、载荷，再由对端回一帧。关闭唯一对端（或让对端静默）后重复发送，预期发端记录 `BusError` 或 `Timeout`；恢复后再次检查双向收发。片内回环与两节点测试分别留存日志。
