# 任务 01 需求与验收

依据《Helios 27赛季电控组招新考核题》任务 01 和总提交要求。各项进度见[实施路线](roadmap.md)。

| 题目要求 | 工程交付 | 验收方法 |
| --- | --- | --- |
| 参考跃鹿，分层、可扩展，使用截至 C++17 的特性 | BSP、Module、Application，共用状态码和日志 | 阅读调用链，检查业务代码依赖；用同一应用编译两种 MCU |
| 封装 UART/USART、CAN、I²C，每个外设至少两种方式 | 通信外设阻塞/中断，显示用 SPI 阻塞/中断，定时器轮询/中断和 PWM 更新确认 | 分别触发各模式；记录开始、完成、超时和下一次操作 |
| 封装所购物资 | MPU6050、七针 OLED、两个 SG90 实例；CAN 收发器、USB-CAN 和 USB-TTL 按物理接口使用 | 读取身份和六轴数据、观察边框和采样显示、两路独立动作、两端收发 CAN |
| FreeRTOS 任务划分 | 说明每个任务的优先级、周期、栈、通信和取舍 | 运行期记录任务活动、栈余量和队列溢出 |
| 初始化失败、通信超时、数据校验失败有返回值与统一日志 | 注入错误参数、设备无响应、半帧、坏校验和 CAN 无应答 | 保存日志，验证异常后的下一次操作 |
| 另一型号 STM32 最小移植 | F407ZGT6 运行共用的串口回送和定时器代码 | J-Link 烧录，记录固件版本、串口数据和定时事件 |
| 完整 Git 历史及仓库内的开发文档、视频、AI Session | 分阶段提交；附架构图、目录、接口、移植、参数、测试和问题记录 | 由干净检出重建；下载仓库后能找到原始证据 |

题面截止时间为 11 月 30 日 12:00。硬件实测待回传的条目保持待验状态。
