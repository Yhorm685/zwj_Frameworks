# SPI 与 OLED

本适配面向 128×64、四线 SPI 的 SSD1306 兼容屏。SPI1 使用 CubeMX 配置的 SCK 和 MOSI，PA4 接 CS，PB10 接 DC，PB11 接 RES。模块需要接电源并与板卡共地。屏幕丝印、驱动型号、电压及接口模式以实际模块为准。

`showPattern` 每次复位屏幕，发送初始化序列，再按页写入带斜线的棋盘格。整屏四边连续点亮，从左上角开始顺时针分别有 1、2、3、4 条短线。用外框查行列偏移，用角标查屏幕方向。`showSample` 把 MPU6050 的 X 轴原始加速度绘制成中心零点的水平条；±1 g 距中心约 32 列。同一页面后续刷新仅写数据所在的一页。旋转传感器可观察方向变化。

轮询适合短命令。需要并行调度时，`startDisplay` 将最多 128 字节复制到 BSP 的静态缓冲，启动 SPI 中断并返回票号。集成版中，SPI1 的发送完成或错误回调释放 CubeMX 二值信号量 `spiDone`。等待任务唤醒后检查 HAL 状态并释放 CS。任务应调用 `wait` 或 `cancel` 结束该请求，超时会释放 CS 并复位控制器。人工恢复可调用 `spi::recover`，再用 `showPattern` 重新初始化显示器。SPI 发送成功只能说明本端完成移位，屏幕是否点亮和图案是否正确由照片或视频确认。
